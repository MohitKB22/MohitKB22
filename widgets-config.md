## 1–2. Stats, Top Languages & Pinned Repo Cards (github-readme-stats)
Generated as static SVGs by `.github/workflows/readme-stats.yml` (runs daily, on manual dispatch, and whenever that workflow file changes) and committed to `profile/`. This avoids the rate-limited public Vercel instance.

```markdown
<img height="175" src="./profile/stats.svg" />
<img height="175" src="./profile/top-langs.svg" />
<a href="https://github.com/MohitKB22/AI-BASED-RESUME-ANALYSER"><img src="./profile/pin-resume-analyser.svg" width="49%" /></a>
```
**Change card options:** edit the `options:` query string for that step in the workflow.  
**Add a pinned repo:** copy a `Pin —` step, change `repo=` and `path:`, then reference the new SVG in the README.  
**Private contributions:** add a classic PAT (scopes `repo`, `read:user`) as the repo secret `GRS_TOKEN`; the workflow uses it automatically.

## 8. Metrics Widget (lowlighter/metrics)
Advanced self-hosted widget. Requires GitHub Actions setup.
```yaml
# .github/workflows/metrics.yml
name: Metrics
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
jobs:
  github-metrics:
    runs-on: ubuntu-latest
    steps:
      - uses: lowlighter/metrics@latest
        with:
          token: ${{ secrets.METRICS_TOKEN }}
          user: MohitKB22
          template: classic
          base: header, activity, community, repositories
          plugin_isocalendar: yes
          plugin_isocalendar_duration: full-year
          plugin_languages: yes
          plugin_languages_indepth: yes
          plugin_topics: yes
          plugin_topics_limit: 20
```
**Placement:** Advanced Stats section  
**Full docs:** https://github.com/lowlighter/metrics
